# 你能关掉吗？

一个围绕日常上网任务的浏览器解谜游戏：找官网、加兴趣群、买胶片、安装游戏平台、找网盘资料，以及购买游戏并准备加速器。玩家通过域名、发布者、群号、文件类型和表单行为识别陷阱。

[在线试玩](https://tyrantqiao.github.io/canYouCloseThat/) · [部署记录](https://github.com/tyrantqiao/canYouCloseThat/actions/workflows/pages.yml)

项目使用 GitHub 默认域名 tyrantqiao.github.io，不绑定自定义域名。

## 当前关卡

| 顺序 | 关卡 | 任务与主要线索 |
| --- | --- | --- |
| 1 | 帮我找到官网 | 搜索星河浏览器，核对域名与发布者，点击验收即可通关，无需清空弹窗。全程未点击弹窗可获「万花丛中过，片叶不沾身」称号。 |
| 2 | 熊友，买卷胶片 | 从北极熊桌面任务栏打开某熊聊天软件，经联系人、查找群、群聊与私聊，在 12 个相似群中核对群号，回答入群问题，辨别诈骗昵称，与群主私聊并完成正确店铺订单。 |
| 3 | 先把 Steam 装好 | 为玩白神话悟空，从桌面打开冲浪浏览器，在地址栏输入 xdu.com 并回车进入 X 度，再搜索 Steam，核对网址与 Valve 发布者，避开下载助手，下载安装客户端。下载完成不算通关。 |
| 4 | 讲义在哪个盘 | 核对网盘分享者与分享号，输入提取码，辨别 PDF、双扩展名 EXE 和下载器压缩包，普通下载正确讲义。 |
| 5 | 买到游戏，再加速 | 购买绝地求死，打开自己的游戏库确认入库；安装官网的疾风并取消推荐组件，按队友区域和服务类型测试线路，进入语音才完成开黑准备。 |
| 6 | 请它出去 | 2016 家用电脑：关闭 2346 广告，先结束守护再结束消息进程，经控制面板卸载程序。理解否定、保留项与捆绑推荐；误装软件和残留组件必须清理，最后打开准考证打印预览。 |

真假收款页具有相似外观；假网站缺少验证码，对错误口令也提示成功，但不会产生有效订单。玩家可用假口令试探，向假站提交关卡口令会扣耐心。验证码只是关卡线索之一，需结合域名、收款方和密码校验判断。

所有关卡不限时，每次尝试有三格耐心。搜索、浏览和返回不扣分，触发陷阱会扣耐心，可返回纠正；耐心耗尽可以重试。下载与安装有独立进度，暂停冻结，重试清除。提示与练习模式会标记辅助通关；暂停仅冻结时间与进度，不改变成绩资格；无辅助最快纪录保存在当前浏览器。

第六关已接入游戏，详细流程见[卸载 2346 的设计方案](./LEVEL_6_UNINSTALL_DESIGN.md)。任务栏右键或开始菜单「系统工具」打开任务管理器；Ctrl+Shift+Esc 也可用。普通关闭、返回和取消不扣分；结束进程不等于卸载。新增软件只由明确承诺产生，下载和安装均可取消，取消安装保留完整包，可从「下载」移除。程序列表和任务管理器可以留着通关；清理后仍保留本次误点历史。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。

```sh
npm test          # 核心任务、陷阱、恢复与存档测试
npm run build    # TypeScript 检查与生产构建
npm run preview  # 预览 dist 产物
```

## 项目结构

- src/game.ts：关卡列表、游戏生命周期、耐心与存档。
- src/mission.ts、src/search.ts：第一关浏览器任务与搜索结果。
- src/scenarios.ts：兴趣群购买与网盘任务。
- src/gaming.ts：Steam 安装、游戏购买与加速器任务。
- src/uninstall.ts、src/uninstall.css：第六关进程、软件目录、卸载向导、误装清理与 Win7 桌面呈现。
- src/main.ts：界面渲染、事件、进度与结算。
- src/*.css、src/sound.ts：布局、视觉、减少动态效果与弹窗音效。
- tests/：使用 Node.js 测试运行器的规则测试。
- AGENTS.md：项目协作约定。
- [GAME_DESIGN_SPEC.md](./GAME_DESIGN_SPEC.md)：当前游戏设计规约、操作语义、年代原则、资产索引与验收要求。

## 运行边界

所有聊天、账号口令、验证码、钱包、付款、下载、安装和系统变化都仅为游戏内状态。不会发起真实支付、下载软件或运行本机程序。第五关中的游戏售价和加速器是剧情设定；Steam 安装来源参考 [Steam 官方说明](https://help.steampowered.com/en/faqs/view/099E-F5D1-8780-4778)。

手机与桌面均可操作，游戏内长页面独立滚动；支持减少动态效果。localStorage 不可用时仍可游戏，但纪录只在当前页面内存中保留。

## 战绩卡与图片导出（已实现）

战绩卡以「上网称号 + 你是一个……的人」为视觉主体：零误点成功按关卡给出画像，本关含重试误点后通关使用恢复型画像，失败仅展示本次画像，不发放通关成就；原有关卡成就置于称号区，辅助标记继续独立展示。HTML 与本地 PNG 共用结算快照和文案。六关成功和失败结算共用战绩卡：关卡与年代、本次用时、本轮累计误点、失败和主动重试次数、辅助标记、真实称号，以及按关卡编写的挑战文案。累计统计不伪装成单关数据，失败不发放通关称号，不提供虚构排名。

“保存战绩图片”在本地生成宽 1080、基础高 1530 的 PNG（随步骤轨迹及整轮明细增加高度） 并发起浏览器下载；“预览 / 长按保存”提供原始图片，支持用户长按或右键保存。下载是否进入相册由浏览器决定，页面不宣称已写入相册。生成失败可重试或截图；重复点击生成期间禁用，重试、换关和回大厅丢弃旧结算快照及预览 URL。导出只读取结算快照，不影响误点、用时、存档和辅助状态。

实现入口：src/share-card.ts（文案、快照、HTML 与 Canvas 绘制），src/share-card.css（响应式布局），src/main.ts（结算与导出事件）。复用游戏统计、称号、字体配色与有限结算彩纸，不增加依赖、远程素材或上传。图片内试玩地址固定为项目公开地址，不包含 localhost、本机路径或玩家输入。

## 本轮总战绩卡（已实现）

每次从大厅选关启动独立一轮，通过“下一关”延续这轮。任意通关页可切换“查看本轮总战绩 / 查看单关战绩”；第六关通关默认展示总卡。从第一关顺序完成六关标为“连续六关通关”，中途开始标为“本轮分段挑战”，明确完成数量，不拼接历史最快纪录或之前独立选关的成绩。

总卡展示累计用时、误点、失败、主动重试、辅助标记，以及逐关累计用时和误点；失败与重试的时间计入相应关卡。同关再次通关更新这一行，不重复添加。总卡支持本地 PNG 导出和图片预览，尺寸 1080×1780；单关卡仍为 1080×1350。

本轮账本由 src/run-record.ts 的 RunRecord 管理，src/share-card.ts / src/share-card.css 复用现有卡片设计；src/main.ts 只接入生命周期、切换和导出。当前本轮明细仅在页面会话中保留；刷新或大厅重新选关开始新轮，原有本地最快纪录存档不变。

## 趣味性优化（2026-10-12，已实现）

- 第一关论坛使用记录和新闻存档可与官网开发日志交叉阅读；阅读是可选探索。官网验收按钮前移，减少被广告遮挡的情况，仍允许带着弹窗完成任务。
- 第二关支持自由输入及话题按钮询问库存、扫街和冲洗；不同人物给出不同回应，问答随会话保存，最小化后仍保留。入群答案留在群公告，问答不扣耐心，也不强制作为通关条件。
- 第三关安装完成显示客户端与快捷方式回报，室友留言衔接后续游戏库准备；标准地址栏入口和安装完成判定不变。
- 第四关增加只读文件预览：PDF 的页数、署名、目录和打印备注可核验，安装程序不能当作讲义预览，错误分享中的内容也不同。预览不执行或下载文件，不影响原有直接下载路线。
- 第五关正常路线为：商店购买 → 打开自己的游戏库 → 安装疾风并取消推荐组件 → 选择并测试联机线路 → 进入语音。假到账不会入库；商城专线延迟低但不能联机，区域不匹配也不能与队友开局。测试错误不扣耐心，可换线重测或取消；暂停冻结测试，从头重试清理所有新增状态。
- 第六关增加清理状态清单，守护或自动恢复使消息服务复活时显示具体原因；简化守护确认与清静版卸载的重复否定措辞，保留组件与捆绑项仍需判断。

复用现有渲染、CSS 与本地音效，无新依赖或外部素材。当前剧情与线路数据固定，尚未加入随机线索或分支剧情。状态测试和实际浏览器验证范围见 [TEST_REPORT.md](./TEST_REPORT.md)。
