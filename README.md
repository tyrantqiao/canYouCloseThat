# 你能关掉吗？

一个围绕日常上网任务的浏览器解谜游戏：找官网、加兴趣群、买胶片、安装游戏平台、找网盘资料，以及购买游戏并准备加速器。玩家通过域名、发布者、群号、文件类型和表单行为识别陷阱。

[在线试玩](https://tyrantqiao.github.io/canYouCloseThat/) · [部署记录](https://github.com/tyrantqiao/canYouCloseThat/actions/workflows/pages.yml)

项目使用 GitHub 默认域名 tyrantqiao.github.io，不绑定自定义域名。

## 当前关卡

| 顺序 | 关卡 | 任务与主要线索 |
| --- | --- | --- |
| 1 | 帮我找到官网 | 搜索星河浏览器，核对域名与发布者，点击验收即可通关，无需清空弹窗。全程未点击弹窗可获「万花丛中过，片叶不沾身」称号。 |
| 2 | 熊友，买卷胶片 | 从北极熊桌面任务栏打开某熊聊天软件，经联系人、查找群、群聊与私聊，在 12 个相似群中核对群号，回答入群问题，辨别诈骗昵称，与群主私聊并完成正确店铺订单。 |
| 3 | 先把 Steam 装好 | 为玩白神话悟空，从桌面打开冲浪浏览器，在地址栏输入 xdu.com 并回车进入 X 度，再搜索 Steam，核对网址与 Valve 发布者，避开下载助手，下载安装客户端。下载完成不算通关。 |
| 4 | 讲义在哪个盘 | 核对网盘分享者与分享号，输入提取码，辨别 PDF、双扩展名 EXE 和下载器压缩包，普通下载正确讲义。 |
| 5 | 买到游戏，再加速 | 在正确的 Steam 网页购买绝地求死，再找到疾风加速器官网并安装，取消默认推荐工具栏与主页修改。两项目标完成才通关。 |
| 6 | 请它出去 | 2016 家用电脑：关闭 2346 广告，先结束守护再结束消息进程，经控制面板卸载程序。理解否定、保留项与捆绑推荐；误装软件和残留组件必须清理，最后打开准考证打印预览。 |

真假收款页具有相似外观；假网站缺少验证码，对错误口令也提示成功，但不会产生有效订单。玩家可用假口令试探，向假站提交关卡口令会扣耐心。验证码只是关卡线索之一，需结合域名、收款方和密码校验判断。

所有关卡不限时，每次尝试有三格耐心。搜索、浏览和返回不扣分，触发陷阱会扣耐心，可返回纠正；耐心耗尽可以重试。下载与安装有独立进度，暂停冻结，重试清除。提示、暂停、练习模式会标记辅助通关；无辅助最快纪录保存在当前浏览器。

第六关已接入游戏，详细流程见[卸载 2346 的设计方案](./LEVEL_6_UNINSTALL_DESIGN.md)。任务栏右键或开始菜单「系统工具」打开任务管理器；Ctrl+Shift+Esc 也可用。普通关闭、返回和取消不扣分；结束进程不等于卸载。新增软件只由明确承诺产生，下载和安装均可取消，取消安装保留完整包，可从「下载」移除。程序列表和任务管理器可以留着通关；清理后仍保留本次误点历史。

## 本地运行

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
```

打开终端给出的本地地址。

```sh
npm test          # 核心任务、陷阱、恢复与存档测试
npm run build    # TypeScript 检查与生产构建
npm run preview  # 预览 dist 产物
```

## 项目结构

- src/game.ts：关卡列表、游戏生命周期、耐心与存档。
- src/mission.ts、src/search.ts：第一关浏览器任务与搜索结果。
- src/scenarios.ts：兴趣群购买与网盘任务。
- src/gaming.ts：Steam 安装、游戏购买与加速器任务。
- src/uninstall.ts、src/uninstall.css：第六关进程、软件目录、卸载向导、误装清理与 Win7 桌面呈现。
- src/main.ts：界面渲染、事件、进度与结算。
- src/*.css、src/sound.ts：布局、视觉、减少动态效果与弹窗音效。
- tests/：使用 Node.js 测试运行器的规则测试。
- AGENTS.md：项目协作约定。
- [GAME_DESIGN_SPEC.md](./GAME_DESIGN_SPEC.md)：当前游戏设计规约、操作语义、年代原则、资产索引与验收要求。
- GAME_DESIGN.md、LEVEL_DESIGN_6.md：历史设计参考；第六关以 LEVEL_6_UNINSTALL_DESIGN.md 和实际实现为准。

## GitHub Pages

.github/workflows/pages.yml 在 main 分支推送或手动运行时执行 npm ci、测试和构建，再发布 dist 到 GitHub Pages。仓库 Pages 来源设置为 GitHub Actions。Vite 使用相对资源路径，可部署到 /canYouCloseThat/ 子路径。

## 运行边界

所有聊天、账号口令、验证码、钱包、付款、下载、安装和系统变化都仅为游戏内状态。不会发起真实支付、下载软件或运行本机程序。第五关中的游戏售价和加速器是剧情设定；Steam 安装来源参考 [Steam 官方说明](https://help.steampowered.com/en/faqs/view/099E-F5D1-8780-4778)。

手机与桌面均可操作，游戏内长页面独立滚动；支持减少动态效果。localStorage 不可用时仍可游戏，但纪录只在当前页面内存中保留。

## 上网回忆册

六关使用各自的剧情时间：2006 家用电脑、2006 网吧聊天、2024 宿舍装机、2012 班级网盘、2026 周末开黑、2016 家用电脑。左侧关卡信息新增可展开的回忆便签；不同年份是独立场景，价格、钱包和剧情道具不作为历史资料。

- 第一关：本地连接状态、收藏夹、显示器旁的上网卡、官网开发日志和分辨率页脚。浏览可疑网页只展示风险线索，不会自动安装或随停留扣分；同意安装、下载、付款与错误验收才触发陷阱。
- 第二关：网吧下机留言、老邮局扫街约定、800 像素群相册、片筒、冲洗扫描费用和与场景相符的胶片保质期。
- 第三关：宿舍群的悟空话题、装机清单、移动硬盘与客户端快捷方式说明。
- 第四关：班级 BBS、U 盘转存、24 页黑白讲义、曝光记录表和 A4 双面打印；XC2006 是社团分享编号。
- 第五关：语音频道等人、自己的游戏库、线路准备与推荐组件核对。

测试覆盖五关完整业务目标、错误分支纠正、假成功、暂停进度和重试清理。详见 tests/journey.test.ts；测试检查内存状态，不发生真实支付或安装。

窄屏聊天将成员资料与群公告放到消息下方，展开关卡侧栏时正文仍可阅读。测试范围和修复记录见 TEST_REPORT.md。

兴趣群关键词搜索将竞价推广的冒牌群排在前面，仅以浅色小字“推”提示推广；正确群排在匹配结果末尾。排名不代表群身份，需核对群号和成员信息。精确搜索群号 73021680 仍只返回正确群，搜索与浏览不扣耐心。

第三关从桌面开始：打开冲浪浏览器 → 空白页地址栏输入 xdu.com 并回车 → 在 X 度检索 Steam → 核对官网、下载和安装。重试回到桌面；从下载或官网返回时保留搜索关键词。

第三关浏览器启动为 about:blank，地址栏可输入网址，支持回车或“转到”、前进和后退；搜索页与结果页分别进入历史。输入错误网址显示游戏内错误页，可修改后重试；已知剧情网址可直接打开，所有网址均由本地状态模拟，不访问真实网站。取消安装保留已下载安装包，关闭下载窗口可返回来源网页再打开安装包。群聊发送消息不再自动切换为私聊，打开新的网盘分享会清理上一次的文件选择。

第三、第五关共用 X 度标题搜索结果、安装包信息与取消恢复流程；第五关取消加速器安装后也可直接重开已下载文件。下载来源独立于当前浏览页面保存。2024/2026 搜索页使用视频、资讯分类，2006 页面保留当时的分类。

第三、第五关的 X 度搜索表单使用局部居中样式，与标志、分类导航保持同一中心线；窄屏输入框可收缩，搜索按钮与输入框底部对齐。

聊天记录按好友、群聊、群主私聊隔离，重新打开同一会话保留记录；最小化恢复原会话，关闭窗口后重开进入联系人。离线好友允许留言，皇冠和私聊按钮对应标有“群主”的成员。网盘精确分享号仅返回对应分享；目录数据同时驱动界面与状态校验。

资产复用：本轮未新增图片、音效或依赖，复用已有搜索页、桌面、聊天样式和本地声音。入口与复用边界见当前设计规约，检查记录见 TEST_REPORT.md。

第四关已实现桌面网盘辨认入口：七个近似网盘快捷方式，任务栏预置三个可疑网盘窗口入口。林林的 BBS 留言提供发布者与服务地址，窗口展示对应身份。查看、切换、关闭不扣耐心，确认安装推荐组件才扣分；真正网盘才可提取并完成 PDF 下载。最小化、关闭与重开保留正确网盘的资料流程，从头重试清理全部状态。复用网盘目录和聊天窗口 CSS，不新增外部素材。

第四关桌面外观已升级为 Windows 7 Aero / Windows XP Luna，可通过“桌面外观”切换，默认 Win7。开始菜单可启动应用；支持窗口最大化/还原，任务栏固定，资料正文独立滚动。桌面 SVG 位于 `src/assets/desktop/`，独立外壳样式为 `src/desktop.css`；现有美术资产、来源与复用边界统一见 [ART_ASSETS.md](./ART_ASSETS.md)。当前仅第四关接入这两套系统外观。
